About This Project

Project Overview

This project implements a Credit Risk Classification system using Logistic Regression. Given a loan applicant's financial and personal attributes, the model predicts whether the applicant is a good or bad credit risk, and further categorises them into Low, Medium, or High risk based on the predicted probability.

Dataset

Name: Statlog (German Credit Data)
Source: UCI Machine Learning Repository
License: CC BY 4.0 (Creative Commons Attribution 4.0)
Samples: 1,000
Features: 20 (7 numerical, 13 categorical)
Target: Binary — 1 (Good Credit), 2 (Bad Credit)

The dataset was donated by Prof. Dr. Hans Hofmann, Institut für Statistik und Ökonometrie, Universität Hamburg. It classifies people as good or bad credit risks based on a set of attributes.

Methodology

  • Data Cleaning: Duplicate removal, missing-value imputation
  • Encoding: One-Hot Encoding for categorical features
  • Scaling: Standard Scaler for numerical features
  • Split: 80/20 stratified train-test split
  • Model: Logistic Regression with balanced class weights
  • Risk Categories: Derived from P(Bad Credit) thresholds (≤30% Low, 30-60% Medium, >60% High)
  • No Data Leakage: Preprocessor fit on training data only

Limitations & Future Work

Limitations
  • Small dataset (1,000 rows)
  • German-specific financial context
  • Binary model extended to 3 classes via thresholds
  • No feature importance explainability UI
Future Enhancements
  • Add SHAP / LIME explanations
  • Support additional ML algorithms
  • API endpoints for integration
  • User authentication & history
  • Batch prediction upload
